# Confidence Huang

<p align="center">
  Evidence-first tools · Agent Skills · Practical workflow software

I build small, inspectable systems for turning messy work into clear next actions: tools that govern agent capabilities, workflows that turn accessible videos into learning notes, and software that keeps career-service work inside explicit boundaries.

## Public work

| Project | What it does |
| --- | --- |
| [`skill-lifecycle-manager`](https://github.com/Confidence-huang/skill-lifecycle-manager) | Governs Skill and plugin inventory, verification, installation, updates, backups and evidence across Windows and Linux. |
| [`bilibili-douyin-video-learning`](https://github.com/Confidence-huang/bilibili-douyin-video-learning) | Turns accessible Bilibili and Douyin videos into structured Chinese learning notes, review material and action lists. |
| [`careerpathdesk-website`](https://github.com/Confidence-huang/careerpathdesk-website) | 介绍 CareerPathDesk 产品并提供第一方演示入口。 |
| [`careerpathdesk-frontend`](https://github.com/Confidence-huang/careerpathdesk-frontend) | Implements the Vue 3 / TypeScript role-based frontend for owners, staff and students. |
| [`careerpathdesk-backend`](https://github.com/Confidence-huang/careerpathdesk-backend) | Implements the Go / PostgreSQL service boundary for authorization, transactions and minimal audit evidence. |

The three CareerPathDesk repositories form one product story:

```text
website  →  frontend  →  backend
介绍与演示    角色工作台     权限、事务与审计
```

## Common thread

- Evidence before claims: a status label should point to a reproducible check.
- Explicit boundaries: credentials, private data and production actions stay outside public examples.
- Human-readable workflows: the shortest useful path should be visible before implementation detail.
